# Продуктовое описание проекта

**Главный сайт: ТД Ангара**

## Цель проекта

Разработать обновленный сайт-каталог для компании по продаже пиломатериалов с возможностью:
- просмотра товаров,
- добавления товаров в корзину,
- отправки заявки,
- обработки заявок через встроенную админку.

## 1. Редизайн сайта

Необходимо выполнить полный редизайн текущего сайта.

**Основные задачи редизайна:**
- современный визуальный стиль,
- улучшение читаемости,
- адаптивность под мобильные устройства,
- упрощение навигации,
- акцент на каталог товаров,
- повышение конверсии в заявку.

## 2. Административная панель

Админка должна содержать 2 основные вкладки:
- Товары
- Заявки

## 3. Вкладка "Товары"

Раздел предназначен для управления каталогом.

**Функции:**
- создание товара,
- редактирование товара,
- удаление товара,
- загрузка фото товара,
- изменение цены,
- изменение наличия.

### Поля товара

Каждый товар содержит:
- название,
- описание,
- цена,
- наличие (количество),
- единица измерения,
- фотографии,
- ограничение порядка дробления.

### Ограничение порядка дробления

Для каждого товара задается минимальный шаг заказа.

**Примеры:**
- шаг 1 → можно заказать 1, 2, 3,
- шаг 0.5 → можно заказать 0.5, 1.0, 1.5,
- шаг 0.1 → можно заказать дробные значения.

Система должна:
- автоматически валидировать ввод количества,
- запрещать ввод значений, не соответствующих шагу.

### Единицы измерения

Единицы измерения задаются вручную в админке.

**Примеры:**
- шт,
- м²,
- м³,
- пог.м,
- пачка.

## 4. Синхронизация каталога

Карточки товаров на сайте должны автоматически синхронизироваться с админкой.

При изменении товара в админке на сайте обновляются:
- цена,
- наличие,
- описание,
- фотографии,
- единица измерения.

## 5. Карточка товара

Карточка товара на сайте должна содержать:
- фото,
- название,
- описание,
- цену,
- единицу измерения,
- наличие,
- поле выбора количества,
- кнопку "Добавить в корзину".

## 6. Корзина

Пользователь должен иметь возможность:
- добавлять товары,
- изменять количество,
- удалять товары.

### Расчет стоимости

Корзина автоматически рассчитывает:
- стоимость каждой позиции,
- итоговую сумму заказа.

Доставка в расчет не включается.

### Оформление заявки

При отправке заявки пользователь указывает:
- имя,
- телефон,
- комментарий.

После отправки создается заявка в админке.

## 7. Вкладка "Заявки"

Раздел предназначен для обработки заявок с сайта.

### Список заявок

Для каждой заявки отображаются:
- номер,
- дата,
- имя клиента,
- телефон,
- список товаров,
- итоговая сумма,
- статус заявки.

### Статусы заявок

Базовые статусы:
- Новая,
- В обработке,
- Завершена,
- Отменена.

### Карточка заявки

Карточка заявки должна содержать:

**Данные клиента:**
- имя,
- телефон,
- комментарий.

**Состав заказа:**
- товары,
- количество,
- цена на момент заказа,
- итоговая сумма.

### История изменений

Система должна фиксировать:
- создание заявки,
- изменение статуса.

## 8. Технические требования

Система должна:
- корректно работать на мобильных устройствах,
- поддерживать загрузку изображений,
- хранить snapshot цены в заявке,
- разделять сущности корзины и заявки,
- поддерживать базовую защиту админки через авторизацию.

## 9. MVP-границы

В проект не входят:
- онлайн-оплата,
- интеграции с CRM,
- интеграции с 1С,
- складской учет,
- роли пользователей,
- несколько менеджеров,
- автоматический расчет доставки,
- бухгалтерия,
- email-рассылки,
- push-уведомления.
